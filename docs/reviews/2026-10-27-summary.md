## Correctness bugs found on the way

- Admin Dashboard "global overview" always shows zeros: nothing calls the global stats loaders.
- Expanding a paged seed overwrites its item count with the page size until the next poll.
- Switching to Korpus Management during a poll (or within 800 ms of the previous switch) leaves it empty until manual Refresh: the shared in-flight flag drops the tab refresh.
- 401 handling is copied 36 times and never closes the log socket or resets state; a previous user's seed candidates can survive into the next login.
- `Corpus.svelte` re-splits joined author strings on `,`, so "Smith, J." style names render as four authors.
- `ingest_import_seed.py` does not link already-existing works to the target corpus.
- `get_bib_pages` Gemini timeout is not enforced; the CLI download counter is overwritten.
- `tests/pipeline-perf.real-pdf.spec.ts` clicks a tab that no longer exists.

## DRY (where the duplication actually costs)

- Frontend: `api.js` repeats the request boilerplate 56 times (five functions skip the 401 tag); status/label/author/cell-text logic lives in App, Corpus and UpstreamBrowser; the refresh plan is written three times; ~1,100 unreachable lines in `App.svelte` (ingest and search tabs, promotion animation, scroll restore) and ~55 dead CSS classes.
- Backend: child-process boilerplate ×6, route guards and 500-handlers ×38, three `tableExists`, two `nonNegInt`, ~500 lines of dead in-memory scheduler code, three unused Python scripts, duplicate indexes (`corpus_works`, `work_aliases`, `search_results`) paid on every insert, schema defined in three places.
- Python: ~10 DOI normalizers with opposite case conventions, "download, hash, mark" ×3, env parsing ×4, duplicate `COALESCE` predicates, OpenAlex request/retry code in three modules.

## What is already good (all three reviewers)

The new SQL reads (`corpusList.js`, `pipelineReads.js`) with golden tests; the refresh scheduler itself; worker settings refresh with atomic publish; lease-based work claims; the production image; test coverage of the recent work.
